# 10-апта: Толық еркін камера

## 1. Sensitivity таңдауы
* **Таңдалған мән:** `0.1f`
* **Себебі:** Бұл мән тінтуірдің қозғалысын тым сезімтал емес, қалыпты әрі басқаруға өте ыңғайлы етеді. Камераны бұрған кезде айналуы бірқалыпты жұмыс істейді.

## 2. 1-тапсырма: Pitch шектеуі
* **Бұзылған мәні:** `pitch = 90.0f` немесе `-90.0f` (тура жоғары немесе төмен қараған сәтте).
* **Түсіндірмесі:** Шектеуді алған кезде камера тура тік қараған сәтте `cos(90°) = 0` болып, векторлардың есептелуінде `NaN` (Not a Number) мәні пайда болады. Соның салдарынан бағыт векторы жоғалып, экран ақ түске боялып немесе бұзылып қалады.

## 3. 5-тапсырма: Үлкен FOV сұрағына жауап
* **Жауап:** `fov`-ты 90°-қа көтерген кезде көру бұрышы (Field of View) тым кеңейіп кетеді. Нәтижесінде перспективалық проекцияның әсерінен экран шетіндегі объектілер созылып немесе қисық көрінеді. Бұл бағдарлама қатесі емес, 3D графикадағы перспективалық проекцияның қалыпты физикалық/математикалық қасиеті.
